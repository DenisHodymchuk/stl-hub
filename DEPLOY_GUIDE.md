# Як підключити ШІ (Antigravity / Cursor / VS Code) до хостингу STL-HUB вдома

Ця інструкція допоможе швидко розгорнути проєкт на домашньому ПК та підключити ШІ-асистента по SSH до живого сервера (`stl-hub.top`), щоб оновлювати сайт однією командою.

---

## 1. Клонування репозиторію з GitHub на домашній ПК

Відкрий термінал (PowerShell або Git Bash) і виконай:

```powershell
git clone https://github.com/DenisHodymchuk/stl-hub.git
cd stl-hub
pip install -r requirements.txt
pip install paramiko
```

Створи у корені папки файл `config.json` (для локального запуску):
```json
{
  "gemini_api_key": "ТВІЙ_GEMINI_API_KEY",
  "model": "gemini-2.5-flash"
}
```
*(На самому сервері `config.json` вже лежить і налаштований, його повторно завантажувати не потрібно).*

---

## 2. Дані для підключення до хостингу по SSH

Сервер працює на **CloudLinux + LiteSpeed (`lswsgi`)** під керуванням **cPanel**:

- **Домен сайту:** `https://stl-hub.top`
- **Адмін-панель аналітики:** `https://stl-hub.top/admin` (пароль за замовчуванням: `stlhub2026`)
- **IP-адреса сервера:** `45.94.158.225`
- **SSH Порт:** `21098` *(не стандартний 22!)*
- **Користувач (Username):** `stlhubto`
- **Папка проєкту на сервері:** `/home/stlhubto/stlhub_app`
- **Віртуальне середовище Python 3.12 на сервері:** `/home/stlhubto/virtualenv/stlhub_app/3.12`
- **Лог помилок сервера:** `/home/stlhubto/logs/passenger.log`

## 3. Як налаштувати SSH-ключ на домашньому ПК (2 варіанти)

### Варіант А (Найпростіший — додати ключ домашнього ПК у cPanel):
1. На домашньому ПК виконай у PowerShell:
   ```powershell
   cat ~/.ssh/id_ed25519.pub
   ```
   *(Якщо файлу немає — згенеруй його командою `ssh-keygen -t ed25519` і натискай Enter).*
2. Зайди у панель керування хостингом **cPanel** (`https://45.94.158.225:2083`, логін `stlhubto`).
3. Перейди в **«Доступ по SSH» (SSH Access)** → **«Керування ключами SSH» (Manage SSH Keys)** → **«Імпортувати ключ» (Import Key)**.
4. Встав свій публічний ключ (`id_ed25519.pub`) у поле **Public Key**, збережи, а потім натисни біля нього **Manage → Authorize**.
5. Додай у файл `C:\Users\<Твій_Юзер>\.ssh\config` такий блок:
   ```ssh-config
   Host stlhub
       HostName 45.94.158.225
       Port 21098
       User stlhubto
       IdentityFile ~/.ssh/id_ed25519
   ```
   Після цього ти (і твій ШІ-асистент) зможете підключатися просто командою:
   ```powershell
   ssh stlhub
   ```

### Варіант Б (Використати вже створений ключ із cPanel):
1. У cPanel зайди в **«Керування ключами SSH»** → таблиця **«Приватні ключі» (Private Keys)** → завантаж файл `id_rsa` собі на домашній ПК (наприклад, у `C:\Users\<Твій_Юзер>\.ssh\stlhub_id_rsa`).
2. Парольна фраза (passphrase) від цього ключа — та сама, яку ти задавав при генерації ключа в cPanel.

## 4. Що написати ШІ-асистенту вдома (Готовий промпт)

Коли відкриєш проєкт вдома в **Antigravity / Cursor**, просто скопіюй і відправ ШІ ось це повідомлення:

> **Промпт для ШІ:**
> «Привіт! Це наш проєкт STL-HUB. Живий сервер знаходиться за адресою `45.94.158.225`, порт SSH `21098`, користувач `stlhubto`. Код сайту на сервері лежить у `/home/stlhubto/stlhub_app`, віртуальне середовище Python 3.12 — у `/home/stlhubto/virtualenv/stlhub_app/3.12`. Веб-сервер працює через LiteSpeed `lswsgi` (`passenger_wsgi.py`). Щоб застосувати зміни після завантаження файлів по SFTP/SCP, достатньо виконати на сервері:
> `ps -u stlhubto -o pid=,comm= | grep lswsgi | awk '{print $1}' | xargs -r kill -9`
> Після цього новий воркер автоматично піднімається при першому HTTP-запиті.»

---

## 5. Швидкі команди для оновлення сервера вручну

Якщо ти змінив код локально, закомітив його у GitHub (`git push`), то на сервері можна оновити все або через SFTP, або прямо через SSH:

```bash
# Підключитися до сервера
ssh -p 21098 stlhubto@45.94.158.225

# Перезапустити Python-воркер після оновлення файлів
ps -u stlhubto -o pid=,comm= | grep lswsgi | awk '{print $1}' | xargs -r kill -9
```
