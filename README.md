# STL-HUB — Візуальний пошук 3D-моделей по фото на 6 сайтах

**STL-HUB** — веб-платформа для пошуку 3D-моделей за фотографією або скріншотом одночасно на 6 найбільших світових базах моделей для 3D-друку:
- **MakerWorld** (включно з прямим візуальним пошуком по зображенню)
- **Printables**
- **Thingiverse**
- **Cults3D**
- **Thangs**
- **MyMiniFactory**

## Можливості
- **Пошук по фото та з буфера обміну (`Ctrl + V`)**: завантажте фото готового виробу або деталі.
- **Гібридний рушій (Visual Search + Google Gemini 2.5 Flash)**: поєднує візуальний пошук MakerWorld із інтелектуальною генерацією функціональних пошукових тегів.
- **Висока швидкість і пагінація**: збирає до 150+ моделей за один пошук із зручним перемиканням сторінок, фільтрацією за сайтами та ціною («Тільки безкоштовні»).
- **Світла та темна тема** в інженерному стилі.

## Швидкий старт

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Створіть файл `config.json` у корені проєкту (або вкажіть змінну середовища `GEMINI_API_KEY`):
   ```json
   {
     "gemini_api_key": "ВАШ_GEMINI_API_KEY",
     "model": "gemini-2.5-flash"
   }
   ```

3. Запустіть сервер (або відкрийте `run.bat` на Windows):
   ```bash
   python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
   ```

4. Відкрийте у браузері: [http://127.0.0.1:8000](http://127.0.0.1:8000)
