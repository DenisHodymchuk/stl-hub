# STL-HUB — Візуальний пошук 3D-моделей по фото на 6 сайтах

**STL-HUB** — швидка веб-платформа для пошуку 3D-моделей за фотографією або скріншотом одночасно на 6 найбільших світових базах моделей для 3D-друку:
- **MakerWorld** (включно з прямим візуальним пошуком по зображенню)
- **Printables** (GraphQL API)
- **Thingiverse** (Native v2 Search API)
- **Cults3D** (Bing Async + Price Detection)
- **Thangs** (v3 Search API)
- **MyMiniFactory** (AJAX Search API)

## Можливості
- **Надшвидкий паралельний пошук (~2–3 сек)**: паралельний запуск візуального пошуку MakerWorld та Google Gemini 2.5 Flash із пулом з'єднань та кешуванням.
- **Інтерактивне кадрування фото (`✂️ Виділити деталь на фото`)**: виділяйте конкретний об'єкт на зображенні (як у Google Lens), щоб прибрати зайвий фон і підвищити точність пошуку.
- **Пошук безкоштовних аналогів у 1 клік (`📷 Схожі`)**: кнопка на кожній картці моделі дозволяє миттєво знайти візуально схожі або безкоштовні альтернативи цієї моделі на всіх 6 сайтах.
- **Збереження в «❤️ Обране» та «🕓 Історія пошуків»**: зберігайте улюблені моделі у закладках і повертайтесь до попередніх пошуків в 1 клік.
- **Браузерне розширення для Chrome / Edge (`chrome_extension/`)**: шукайте будь-яку картинку з Pinterest, AliExpress, Etsy чи Google Images правою кнопкою миші -> *«🔍 Знайти цю 3D-модель у STL-HUB»*.
- **Світла та темна тема** в інженерному стилі.

## Швидкий старт

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

2. Створіть файл `config.json` у корені проєкту (або вкажіть змінну середовища `GEMINI_API_KEY`):
   ```json
   {
     "gemini_api_key": "ВАШ_GEMINI_API_KEY",
     "model": "gemini-2.5-flash"
   }
   ```

3. Запустіть сервер (або відкрийте `run.bat` на Windows):
   ```bash
   python -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
   ```

4. Відкрийте у браузері: [http://127.0.0.1:8000](http://127.0.0.1:8000)
