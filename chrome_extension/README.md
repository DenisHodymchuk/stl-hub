# 🧩 Розширення STL-HUB для Chrome / Edge / Brave

Це офіційне браузерне розширення для **STL-HUB**, яке додає пункт **«🔍 Знайти цю 3D-модель у STL-HUB»** у контекстне меню (правою кнопкою миші) на будь-якому зображенні в інтернеті (Pinterest, Instagram, AliExpress, Etsy, Google Images, Reddit тощо).

## Як встановити за 30 секунд:
1. Відкрийте у браузері сторінку розширень:
   - **Chrome:** `chrome://extensions/`
   - **Edge:** `edge://extensions/`
   - **Brave:** `brave://extensions/`
2. Увімкніть перемикач **«Режим розробника» (Developer mode)** у правому верхньому куті.
3. Натисніть кнопку **«Завантажити розпаковане розширення» (Load unpacked)**.
4. Оберіть цю папку (`chrome_extension`).

## Як користуватись:
- Наведіть курсор на будь-яку картинку з виробом у браузері -> натисніть **праву кнопку миші** -> оберіть **«🔍 Знайти цю 3D-модель у STL-HUB»**.
- Відкриється вкладка `STL-HUB` і автоматично запуститься візуальний пошук цієї моделі одразу по всіх 6 сайтах!
